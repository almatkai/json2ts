# Json2TS Native V2

Offline Rust conversion plus a concrete compiled-in beta adapter for `index` / **Json2ts** / Generate TypeScript interfaces from JSON. V1 remains beside it unchanged. The exact original icon is in `assets/command-icon.png` (29,082 bytes; SHA256 `0b083ac11c306e7704f359a6d8b15a95a77f6a0b9f2ea76c6d628f8a3d43cd7c`). Original author gbarba; contributor yusifaliyevpro; Tezbar repository almatkai.

Own source SHA: `8186f2229ec907bb3f705d1a641fd7159f0339f9`. Behavior comes from that command and its actual lock: json-ts **1.6.4**, TypeScript **2.9.2** within json-ts, Immutable **3.8.3**, needsquotes **1.0.0**, and embedded Lodash **4.17.4**. V1 uses @raycast/api **1.103.2**, React **19.0.0**, and build TypeScript **5.9.2**. Manifest ranges are not dependency pins.

The form has JSON (`jsonTextarea`) and Interface Name (`rootName`, default `rootName`), with Generate first. It validates empty JSON before empty interface name, converts with `flow:false,prefix:""`, then copies exact generated bytes. There are no preferences, arguments, history, saved drafts, selected-text input, clipboard-read input, paste, or browser actions in this source. None are invented. Runtime conversion is Rust only, offline, without JS/Bun fallback or persistent storage.

The engine preserves tested legacy behavior: source order and duplicate keys, casing and escaping, separate nested interfaces, inline objects, heterogeneous and nested arrays, missing member optionality, name collisions, kind-based reference deduplication, numeric/null/empty cases, and printer newlines. It deliberately retains odd 1.6.4 output such as duplicate `boolean` union entries, prefixed references to differently named array interfaces, and `[]` when an empty array is merged with a scalar. It does not repair the generated TypeScript.

Beta adaptations:

- There is no genuine native HUD/toast or pop-to-root API. Validation failures use native errors. Copy/effect failures return a Form with explicit failure text and deliberate retry actions; the beta renderer recognizes their failure tone. Successful copy uses an inline native status and an acknowledged `window:hide`, then returns the updated Form. Navigation is not claimed to have popped. On reopening the window the same drafts and fresh Generate action remain available; Back uses the beta renderer's ordinary navigation. No fake HUD effects are emitted.
- Copy and hide require strict object acknowledgements (`ok:true`, no non-null `error`, `success` absent or true). Transport errors and malformed or contradictory acknowledgements cannot produce a confirmed success. Acknowledged output survives hide failures. Retry Copy uses the bound computed output, even if an event supplies forged text. Retry Hide Window never recopies. Neither refresh nor replay automatically retries an uncertain effect. If a call is cancelled, a field edit can expose the deliberate retry action; a cleared/disposed session must be reopened. Checkpoints are session-only.
- Field callbacks use `formValues.value`; submission uses the complete form map. Stable field IDs and omitted unrelated controlled values protect queued drafts. Malformed events preserve legitimate bindings. Capability IDs are fresh per launch, process-nonce-backed, and stale/cross-session/disposed IDs fail. This Form has no search results: server search is rejected without mutation; refresh/load-more return unchanged.
- This is a bounded TS-literal/recovery implementation, not the complete TypeScript 2.9 compiler. The executed actual-source oracle covers 2,187 cases, including malformed/truncated text and Unicode. Arbitrary TypeScript programs accepted accidentally by the old compiler parser are outside the native contract and are not exhaustively verified. Unpaired UTF-16 surrogates in emitted names cannot cross Rust's UTF-8 boundary and produce an explicit error; unpaired surrogates in string values do not affect inference. Input is limited to 1 MiB, root names to 16 KiB, parser depth to 64, nodes to 20,000, interfaces to 2,048, tokens to 240,000, and generated output to 4 MiB. Regex complexity exhaustion errors; nothing is silently truncated.

Native V2 is compiled-in. Copying `manifest.json` cannot install executable Rust. See [INTEGRATION.md](INTEGRATION.md) for stable vendoring, dispatch/catalog registration and rebuild instructions, and [VALIDATION.md](VALIDATION.md) for checks and headless limits. Both OS verification records remain **not-run**.

**Known host contract gap:** the pinned beta platform returns JSON null after `window:hide` (platform.rs line 236), and the core router forwards it unchanged. The required strict acknowledgement rule rejects that result. Copy is confirmed, but hide remains unconfirmed even if the native window actually hid. Production integration needs an explicit host acknowledgement after successful hiding; this adapter does not normalize null into success. No host fix is included.
